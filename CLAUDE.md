# Claude Code — Orquestração Local

## Escopo deste repositório

Este arquivo existe dentro do repositório para registrar instruções relevantes ao projeto versionado em `tattoo-studio/`.

## Regras práticas

- Respeitar a stack já adotada: frontend em React + TypeScript + Vite + TailwindCSS, backend em Node.js + Express ESM.
- Evitar mudanças estruturais de arquitetura sem alinhamento prévio.
- Não versionar `.env`, banco SQLite real, sessões do WhatsApp ou backups.
- Priorizar mudanças focadas e consistentes com o código existente.
